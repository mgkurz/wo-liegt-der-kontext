# Wo liegt der Kontext?

Interaktives Begleitmaterial zum Workshop „Vom Prompt zum Kontext" der Hessischen
Lehrkräfteakademie. Die Seite zeigt, wo in ChatGPT, Claude, Gemini und AIS.chat der
dauerhafte Kontext liegt: in den Anweisungen und in den mitgegebenen Dateien. Ins
Chatfeld gehört nur noch die Aufgabe.

**Aufruf:** <https://mgkurz.github.io/wo-liegt-der-kontext/>

Eine einzelne HTML-Datei, keine externen Abhängigkeiten, kein Tracking, keine Cookies.
Alle Eingaben bleiben im Browser der Nutzenden. Läuft auch offline und lässt sich in
Moodle einbetten.
